# 恐怖节奏研究摘记

获取日期：2026-11-15。来源为 Thomas Grip 在 Frictional Games 官方博客发表的 [9 Years, 9 Lessons on Horror](https://frictionalgames.com/2019-10-9-years-9-lessons-on-horror/)，发表日期为 2019-10-15。

本文为自己的简短阅读记录，不保存或再分发原文与图片。原作者讨论了独立惊吓容易变成干扰、场景叙事如何支持恐惧，以及行为漏洞会破坏玩家对世界的信任。对《回煞》的直接启发是减少无关随机效果，让玩家能把声音、场所和当前处境联系起来。

第四轮据此移除按帧随机抖屏和全屋随机压暗，将普通环境声落在实际存在的滴水、木板和纸钱上。追逐使用真实位置的脚步与有宽限的入场，记忆调查暂停外部追逐，回返时恢复。这些具体规则和时间参数是本项目的实现选择，不是原作者对所有恐怖游戏的统一要求。现有 Yarn Spinner 与 Ink 参考继续复用，未引入其他游戏的美术、音频或引擎。
