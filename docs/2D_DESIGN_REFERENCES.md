# 2D 调查篇：参考作品与迭代记录

更新：2026-11-16。老板要求学习优秀作品并持续迭代，且已明确停止 3D。本文记录本轮学习依据、落地选择和验收边界，后续迭代从实际问题继续，不将参考作品的体量当作本项目的完成承诺。

## 信息随发现出现

第三十六轮沿用发现式记录原则，为手记和选证库增加手动地点/原文查找，地点仅来自已读记录，不由全地图补齐，也不自动筛出答案相关卡。长物证库可收起，正在整理的选证与解释在筛选时保持。这里只改善本项目的原文回找负担，复用现有卡片、草稿与原生 details，没有宣称参考作品使用相同控件或复制其界面。

Mobius 官方开发日志 [All Systems Go](https://www.mobiusdigitalgames.com/news/all-systems-go) 介绍《星际拓荒》用日志记录已经发现的信息；[Planet Progress](https://www.mobiusdigitalgames.com/news/planet-progress) 记录了信息整理界面向侦探板演变的过程。这里借鉴的是发现与记录之间的关系，没有照搬其星系模拟或知识解锁结构。

《回煞》原手记会在开局列出学校、医院、事故三段问题，以及所有缺失物证的名称，提前暴露终章。本轮改为只有找到某段相关物证后才出现对应问题，不展示未知物证名。物证卡片从实际地图数据取原文与来源房间；通用文书仍保留阅读时记录的内容。默认目标栏减少整条路线的直接指示，提示由玩家主动索取。

第九轮沿用这一原则处理开场：读到来信后，目标才复述供桌右侧黑布的具体去处。没有读信也能进宅和自行调查，主动提示继续可用。车辆浅色划痕与事故态锈痕前后对应，让玩家有能比较的现场记录；不靠强制对白宣布联系，不给可选观察增加真相计数。此为本项目的探索设计选择，未采用参考作品素材。

第十轮把相同原则应用于衣柜暗门：方向来自实际地上的擦痕与东墙，玩家可观察并记录，再选择挪动；也允许直接尝试。错误方向只提供物理反馈，不扣资源，操作完成才露出通路。这里补足的是“现场依据—玩家操作—空间变化”的关系，不复制参考作品的谜题或代码。

第十一轮沿用已有参考，把井边“读完就拿”改成可观察的钩尖和亮痕，以及相应的取钥匙动作。观察可回查，猜对不要求先点观察，错误无资源惩罚；外形显出钥匙和取后的空钩。此为本项目的小型物件操作，不宣称为自由物理谜题；选项的直接程度仍需实玩反馈。复用本地参考与既有交互框架，没有下载商业素材或增加依赖。

第十二轮处理开场“对白已揭布、画面仍遮住”的矛盾，让布角观察、主动揭开、背面记录和遗像外形对应同一次操作。沿用已有参考中让发现与记录一致的设计启发，以及本地 Yarn 的台词/选项/状态分离思路。守灯纸条取同一地图原文，减少手记与世界读物不一致；这里只补齐本项目的状态表现，没有复制参考作品素材或新增叙事运行库。

第十三轮继续沿用发现式日志的研究，把玩家已经看过的记录连回实际地点：手记可回想已走路线，路线图可按房间回查发现。来源在实际阅读时记录，旧记录未知地点保持未知，不用完整地图数据库补成全知日志。复用现有 Phaser 和记录/路线系统，没有新增参考下载或运行依赖；此为本项目的探索辅助，未实现参考作品的完整侦探板。

第十四轮复查本地 Yarn 的选项与命令接口、已整理的恐怖节奏文章，处理“查看旧物便被强制带走、未解完不能返回”的探索限制。进入记忆、暂回旧宅和提交判断各自对应明确操作；暂离保留事实但不替玩家提交答案，正确提交才改变完成态与环境。返回追逐使用原有预警，不把暂避误作清除危险。这里是本项目对自主调查节奏的调整，不宣称参考作品采用相同进出机制，也没有引入其资产或运行库。

第三十五轮继续复读本地 Yarn 的台词/选项分离接口，把同一自主调查原则补到最后物证：先阅读，再选择整理判断；成功或重读之后可继续观察，明确选择才回宅。两份原文从 Maps 同源记录，不新增强制阅读或解锁步骤。这是本项目对原回调的调整，没有复制参考作品的场景，也不宣称 Yarn 提供了相同回返菜单。

第十九轮沿用发现与记录一致的原则，修复日记只有阅读函数、却没进入实际交互注册的问题，并接通同屋衣柜躲藏。原文迁回地图数据，现场与手记共用来源；书本作为桌面调查对象绘在家具上方。这里补齐本项目的实现缺口，没有新增参考机制或复制资产。检查也改为从工厂和焦点进入，避免手填目标把无法发现的物件误判为可玩。

第二十三轮沿用已有发现式日志与玩家自主调查的研究，修正主动提示固定按供品与学校优先的顺序指路。优先回应当前房间与实际进度，材料齐全后提示从手记判断，守灯中途只提示剩余步骤；危险仍优先。这里是本项目对提示上下文的调整，不宣称参考作品使用相同算法，未新增资料下载或运行依赖，也不通过提示自动补发现或完成。

第二十四轮继续沿用发现式记录，把暗室/地下室五处一次性对白迁入原文书流程，让实际读过的环境记录能保留来源、回看并找回现场。保留原文与非核心观察属性，不靠扩大结局计数奖励重复阅读。这里只补齐本项目已有文字的记录方式，没有新增参考机制、下载或依赖；历史按要求移除的正厅纸人保持该决定。

第二十六轮从发现式记录原则继续处理失败恢复：被抓仍重置现场与物品，但不抹去玩家实际读过的文字、走过的路和已提交的判断。保留原物理检查点与追逐结束规则，未提交不算完成；这是本项目的恢复设计选择，不宣称参考作品有相同惩罚或存档机制。复用原状态与存档，没有新增下载或依赖。

第二十八轮继续沿用让路线和实际探索对应的原则，修正五处与反向门偏离的入房落点，让进地下室、阁楼回程和暗室返回保持空间衔接。复用原地图、门触发与已下载的 Phaser 碰撞资料，只调整坐标，不复制参考作品关卡或改变连接；几何核对不能代替真实切图手感。

## 判断必须有事实支撑

第三十轮复读本地 Ink 指南的 Conditional Choices 小节，沿用状态控制选项与文本的思路，把供桌从找齐后一次完成改为搜集与操作交替。各动作校验对应材料，缺料保留进度；按钮不按答案顺序排列，纸条只回查已读原文。这是本项目基于原仪式与存档的调整，不宣称 Ink 或商业参考作品使用相同谜题，没有新增依赖或复制示例代码。

Lucas Pope 的 [Road to the IGF 采访](https://www.gamedeveloper.com/business/road-to-the-igf-lucas-pope-s-i-return-of-the-obra-dinn-i-) 谈到《奥伯拉丁的回归》的事件发现、身份推断及书本整理。这里借鉴的是把已发现的具体事实放在一起，由玩家形成判断；没有实现该作的完整身份网络或多人批量验证。

本轮把“选一句正确态度”改成可以核对的经过：学校黑板与父亲在成绩单上的禁足要求，医院同日 15 时的求助和 18 时的家属拒绝，事故中未解开的安全带与十年前的编号。玩家选择两份已找到的记录，再选择解释并提交。未选、重复选、选无关物证、答错、取消都不会完成记忆。错误后保留当前选择，可以展开原文修正；没有额外扣资源或惩罚。

这是小型的证据配对机制，仍有三个固定解释，不应宣称为自由推理系统。后续应从试玩观察判断是否仍然容易穷举，再决定是否扩大证据关系。

第三十二轮复读本地 Ink 指南的全局变量小节，用已有状态和存档保存玩家未提交的选证与解释，让回现场观察后可以接着核对。它们始终是草稿，重开或读取不算提交，成功验证才形成正式判断；玩家可以清空当前事件重新整理。这是本项目为探索往返补充的机制，没有复制 Ink 示例或宣称参考作品有相同草稿结构，未新增依赖。

第三十一轮继续沿用让玩家自己判断记录关系的原则，移除手记的指定相关物证计数，并让发现一份事件记录后即可尝试选证。学校/医院的情绪线索只引出问题，不证明答案；中性提问不预先断定尚待对照的事实。实际完成仍用原物证与解释核对，没有变成自由输入或自动验证每张物证的系统。复用已有参考与状态逻辑，未新增下载或依赖。

第十六轮继续复用上述事实对照的研究，将实际选中的两份原文与来源放到解释选项之前，减少来回展开卡片的记忆负担。失败后按事件提示核对书写者、时间或痕迹，保留选择，允许换掉其中一份；不逐份报对错，也不自动挑选正确证据。这是本项目的界面与反馈选择，不宣称参考作品有相同机制；没有新增参考下载或运行依赖，正确提交仍沿用原验证规则。

第二十轮将相同研究用于保险箱：原先两份文书各自给出完整答案，现改为同句年份的互补残字，让第二处观察提供实际信息。锁旁直接展开已读原文，玩家自行拼合；保留主动猜中和旧已读完整文本，不设置额外收集门槛。这是本项目对已有文字谜题的改写，没有复制参考作品的谜题、代码或素材，也没有新增依赖。

## 场所承接记忆

第三十四轮沿用同一场所叙事研究，让终章的“前行/回宅”对应东/西实际位置，把护栏断口移至车头前并补连续护栏、标线与刹车痕。复用上轮物理与旧位置恢复，不新增推理物证或难度门槛；具体道路构图与三张像素配方属于本项目，没有复制商业事故场景或素材。主动调查与结局确认保留，真实光照和绕行节奏仍待试玩。

第三十三轮复用本地 Frictional 场所叙事摘记，为学校补上课桌排/讲台/侧窗，为医院分出候诊、病区和票据桌，让已有物证有可辨认的承载器物。家具实际阻挡移动，保留中央与绕行路线，背景不新增调查任务；具体布局、九张像素配方与旧位置恢复都是本项目选择，没有复制商业场景或素材。官方 Phaser 物理 API 新参考见参考索引。素材和来源布局预览仅证明构图可核对，光照、遮挡与移动仍需实玩。

第二十二轮继续沿用场所叙事研究，让终章两个去处有路标石阶和旧宅门口的外形，补上近处的明确名称。这里处理的是染色地砖难以表达方向的问题，保留原对白、推理与确认，不在素材上标出结局好坏。使用本地像素配方，没有复制参考作品资产或新增机制；远处辨识与比例仍需实际光照下确认。

第二十一轮继续沿用场所支持叙事、减少孤立惊吓的研究，把原开棺条件落实到可见的三圈红线：学校、守灯和医院完成后各松一圈，锁仍需钥匙。玩家可记录和尝试，失败指出实际受阻的位置，开棺前确认进入最后记忆。这里只把本项目原有状态变成环境反馈，没有复制参考作品谜题，也未新增条件；锁声取代此处两秒突发低音。效果仍需实际光照和试玩确认。

第十八轮继续沿用已有场所叙事与 Yarn 选项/状态分离的参考，处理饭与火柴只在对白里出现的问题。让两件物品先有可见位置，主动取走后留下对应印痕，换房和读档保留结果；不要求先点额外观察，也不新增供品种类。这里只补齐本项目的取物选择与环境变化，不宣称参考作品使用相同搜集机制。复用已有资料和程序纹理，没有新增下载或运行依赖。

第十七轮沿用既有场所叙事研究，处理走廊封窗只能靠透明触发区发现的问题。让横木、内侧窗扣和抓痕成为可见对象，阅读说明钉尖与钉头的方向，手记保留同源原文，玩家可回查具体事实。这里只补齐原有观察的外形与记录，没有新增开窗谜题或复制参考作品的场景资产；仍需实玩确认暗处是否看得清。

第十五轮继续复用现有场所叙事研究，把不同场所的关键调查物从通用相框中区分出来。黑板与成绩单上的不同处理、诊室和空床的留单、断裂护栏外的纸飞机，都对应已有文书的具体事实。用专用轮廓帮助玩家决定走向哪里，完整文字继续留在阅读界面；这是本项目对可观察信息的表现调整，没有复制参考作品资产，也没有新增叙事机制或解谜门槛。

第六轮继续复用已有官方资料和本地工程，把“场所承接记忆”的设计推论落实到空间材质与物件外形：学校、医院和家庭空间不再只靠同一木地板染色区分，纸钱、香和钥匙也有独立形状。地面不再随机生成与物证相同的纸屑，避免暗示每片垃圾都值得调查。这里是本项目对信息可读性的具体处理，没有复制参考作品资产。素材配方与预览索引见 [2D 美术资源](../assets/2d/README.md)。

赤烛的《返校》[官方 press kit](https://redcandlegames.com/presskit/sheet.php?l=en&p=detention) 将 2D 恐怖、地方历史与民俗结合。对《回煞》的设计启发是让家庭物件参与叙事。这是本项目的设计推论，并非官方逐条准则，也没有下载或复用商业游戏素材。

此前回到走廊会用延时对白宣告“照片变了”，物件实际没有变化，还可能覆盖正在阅读的文字。本轮删除该强制对白，按已完成记忆派生房间变体：学校记忆完成后，第三张旧照改用另一张像素纹理，显出被遮住的人物与相纸文字；医院记忆完成后，药柜小间门外出现可读的处方封套。两者都由玩家主动调查，不计入核心线索数量，不触发新追逐，不改变通路和共享地图定义。重开或读取早期检查点会恢复相应房间状态。

## 复用与文件入口

第二十五轮补充 W3C [Dialog (Modal) Pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) 的一手参考，从 [w3c/aria-practices](https://github.com/w3c/aria-practices) 下载模式原文与许可，见 [参考索引](references/README.md)。核对长内容以标题/静态文本起始聚焦、Tab 首尾循环、关闭后回到触发者的说明，落实为本项目阅读层的焦点处理；没有复制其演示脚本或新增依赖。原生浏览器焦点、读屏和滚动仍需实际验收，脚本表面不能替代。

第二十七轮复用同一模式关于难以撤销操作的初始焦点建议，为标题重新开始添加确认，默认选择保留进度。使用浏览器原生 dialog，并阻止底层画布按钮与启动快捷键穿透；只有明确确认才清除。没有新增下载或复制示例脚本，原生行为与触屏仍待试玩。

## 验证与后续

第三十七轮下载项目同版本 Phaser 的 KeyboardManager/KeyboardPlugin 官方源码，核对全局 preventDefault 与临时转交 DOM 的 disableGlobalCapture API，用于阅读层输入边界。场景游戏键盘和浏览器默认行为分别保存/恢复，输入法组字键留给输入法；不清除键位或引入输入库。来源和 MIT 许可见参考索引，模拟检查不能证明真实输入法已经验收。

第二十九轮从 [mdn/content](https://github.com/mdn/content) 下载 Web Audio 指数渐变的官方文档与许可，来源见 [参考索引](references/README.md)。按终值必须大于零的约束修复听觉范围边缘；复用原 Web Audio 系统，补立体声能力回退和可选麦克风取消/去重，不增加框架或复制示例。音频节点模拟只能证明调用与释放规则，实际设备和听感仍待试玩。

第四轮研究 Thomas Grip 的 [9 Years, 9 Lessons on Horror](https://frictionalgames.com/2019-10-9-years-9-lessons-on-horror/)，自己的本地摘记见 [horror-pacing-notes.md](references/horror-pacing-notes.md)。借鉴减少孤立惊吓、用叙事场所支持恐惧的思路，落实为实际物件声、追逐前预警和追逐后的安静间隔。每个声效的位置来自 Maps，不再随机假造敌人脚步；敌人脚步则取真实位置。预警时间、距离、记忆暂停追逐和理智速率均为本项目选择，尚未经过真实体验调优。

第三轮继续沿用“记录已发现的信息”这一原则，没有重复下载参考或引入新框架。发现型手记之外补充了已走房间与门的示意图，并让调查反馈区分阅读、完成操作和内容变化；这是《回煞》自身的导航设计，不宣称参考作品使用相同地图机制。实现见 `Exploration.js`，物证选证与核心剧情门槛继续沿用第二轮规则。

源码复查同时找到了前期卧室日记直接写明死亡的剧透，已经改为未寄出的信等家庭痕迹，明确反转仍由事故物证支持。新增检查覆盖实际路线与门的方向/锁定、旧存档渐进记录、照片版本变化和 NPC 抢焦点；真实图形与手机验收缺口保持不变。

本轮扩展既有 `verify_2d_gameplay.mjs`，用轻量 DOM 表面运行真实按钮处理函数，覆盖开局隐藏事件、原文一致性、错误物证、取消与重试、提示随任务重新分级、房间变体隔离及重开恢复，保留仪式、结局、存档和体力验证。该脚本与现有单文件入口、地图、剧情状态和开始路由检查均通过。

真实浏览器画面、触屏布局、追逐节奏和完整通关仍未验收。此前自动审批拒绝启动 Chrome 无头实例，返回 `blocked by policy`；本轮没有换手段绕过拒绝，也没有把轻量 DOM 检查写成浏览器验收。下一轮优先取得实际试玩反馈，确认提示是否过密、证据选择是否有意义、环境变化是否容易被看见，再安排内容扩展。所有改动仍只在本地，未提交、未推送、未发布。
