# 《回煞》3A 视觉盲测核验量表

## 1. 用途与边界

本文用于只依据最终截图进行匿名 A/B 视觉核验。评审者不得读取实现说明、提示词、资产来源、渲染参数、版本号或候选方案名称，也不得因“工作量更大”“技术更先进”或“更接近某个知名作品”而加分。

量表参考现代写实军事题材与电影化 3A 游戏共有的画面要求：可信尺度、明确焦点、受控曝光、材质分层、空间纵深、叙事性细节和稳定的图像完整性。它不要求《回煞》变成军事题材，也不以任何具体商业作品、角色、武器、载具、场景或镜头为复刻对象。所有判断只落在通用视觉属性上。

单张截图不能证明帧率、动画质量、镜头运动、粒子时序、输入延迟或跨场景稳定性。这些项目必须标记为“不可由当前样本判断”，不得靠猜测补分或扣分。

## 2. 盲测样本规范

同一轮 A/B 必须尽量保持分辨率、宽高比、视角位置、镜头焦距、角色姿态、时间、天气、画质档、UI 状态和截图压缩一致。若差异本身就是测试变量，例如新旧打光方案，可以只允许该变量不同。

提交前去除文件名、版本号、作者、方案名和水印，随机决定左右顺序。评审顺序固定为：先用 3 秒判断焦点和第一印象，再以 100% 比例检查主视觉，最后放大检查边缘、材质、接触关系和渲染瑕疵。不得先看局部再倒推整体优劣。

若两张图的构图、曝光或视角差异大到无法隔离测试变量，结论应为“样本不可比”，而不是强行选胜者。截图中未出现的对象或维度记为 N/A，采用可见维度权重归一化，不因“没有角色”或“没有载具”而扣分。

## 3. 五级评分锚点

每个维度先给 0–5 分，允许 0.5 分增量，再按权重换算。总分公式为：`Σ(维度分 ÷ 5 × 权重) ÷ Σ(可见维度权重) × 100`。

| 原始分 | 画面含义 |
| --- | --- |
| 5 | 发布级候选；在正常观看距离和 100% 检查下都高度可信，仅有不影响整体的微小问题 |
| 4 | 强成品感；视觉意图明确，存在少量可定位、可收尾的瑕疵 |
| 3 | 可用但有明显制作痕迹；整体成立，局部或某一系统仍显得游戏化、模板化 |
| 2 | 原型感明显；多项问题持续破坏可信度、焦点或可读性 |
| 1 | 严重未完成；主要内容难辨、空间或材质关系大范围失真 |
| 0 | 无法使用；黑屏、核心内容缺失或画面错误到不能评价目标效果 |

总分只表示该截图的视觉成熟度，不等同于整个游戏品质。建议解释区间为：90–100 为发布级 3A 候选画面，80–89 为接近发布级，70–79 为强纵切片，60–69 为成熟 AA/纵切片，40–59 为可辨认的原型，0–39 为预演或存在严重画面故障。

## 5. 一票否决与分数上限

先做有效性检查，再计分。以下规则优先于总分：

| 级别 | 条件 | 处理 |
| --- | --- | --- |
| S0 样本无效 | A/B 的视角、内容、分辨率或 UI 状态不一致，无法隔离待测变量；截图严重压缩或被裁切 | 不判胜负，要求重截 |
| G0 灾难性故障 | 黑屏、大片缺失材质、核心主体消失、相机落入模型、关键区域被曝光完全吞没，或明显错误覆盖约四分之一以上关键画面 | 总分最高 39；若仅一方触发，另一方直接胜出 |
| G1 系统性破坏 | 主体虽存在但持续不可读；大面积穿模/悬浮；光照、透视或透明关系让空间无法成立 | 总分最高 59，并必须列为首要风险 |

版权或来源无法仅凭普通截图确定。若画面出现高度可识别的第三方标志、角色或标志性设计，只记录“需要来源核验”，不给质量加分，也不在没有证据时直接下侵权结论。后续改进建议只能描述通用形状、材质、色彩和构图目标，不建议复刻具体受保护资产。

## 6. A/B 胜负规则

在样本有效且没有不同级别硬门槛时，用归一化总分差决定结论：

| 总分差 | 结论 |
| ---: | --- |
| 5 分及以上 | 明确胜出；差异通常能稳定影响第一印象或生产完成度 |
| 2–4.5 分 | 小幅胜出；必须指出至少两条可见证据，且不能只来自个人风格偏好 |
| 小于 2 分 | 平局或证据不足；不要为了给答案强行选边 |

总分接近时，按“图像完整性 → 视觉可读性 → 光照曝光 → 材质几何 → 氛围风格”的顺序裁决。技术故障和信息丢失优先于更浓的滤镜或更戏剧化的色彩。若候选图构图并不一致，则构图差异只能作为实际观感证据，不能伪装成单纯材质或打光结论。

置信度分为高、中、低。只有同机位、同内容、同输出规格且差异稳定落在多个维度时才给“高”；只有一处微弱差异或样本条件不完全一致时给“低”。

### 8.2 基线风险优先级

| 优先级 | 风险 | 画面证据与适用边界 |

## 9. 后续复测最小样本集

为了避免只优化一张“英雄截图”，每次大版本至少保留四类同机位对照：默认出生广角、主视觉近景、最暗可玩路径、容易暴露侧面厚度的斜角。若出现人物、武器或载具，再加一张主体占画面高度约三分之一以上的近景。动态效果和性能另行录像或采样，不混入本截图量表。

### 13.3 V3 带债退出判断

**Build 03 可以带 P2 债务退出 V3。** 默认机位达到成熟原型上沿，两个指定近景没有 P0，也未再稳定暴露 P1；上一轮五类 P1 均已解决或降为 P2。改善跨默认、门锁和门缝三个视角成立，不是只针对英雄截图的掩饰性优化。

这里的“退出 V3”只表示该阶段的走廊视觉目标通过，并不代表 3A 发布候选。后续仍需带走的 P2 债务包括：增强门缝对邻近边缘和空气的红色反弹；细化符纸纤维、卷边与多样固定；给横木、卡座和门环补倒角、紧固、崩角与磨损；继续统一门板和写实墙面的细节频率；处理近景左侧死黑。

因此，本轮结论为“V3 可退出、债务进入下一精修阶段”，而不是“资产已达到最终发布质量”。
