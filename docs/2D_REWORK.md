# 2D 主线改造记录

## 第三十七轮：阅读控件使用原生键盘输入

阅读层打开时暂存并停用场景游戏键盘，释放 Phaser 的全局默认行为捕获，让 WASD/空格/方向键留给文本框、下拉和按钮；关闭时清按键并恢复最初设置，换页不覆盖快照。原捕获键位不删除，原本已禁用的设置保持；插件销毁后只恢复保存的共享捕获值。

阅读层和入口对白监听忽略输入法组字/已处理事件，隐藏对白不响应手记中的空格/回车。现有玩法检查覆盖键盘生命周期与 IME 边界，入口 VM 检查执行真实对白监听；实际中文输入法、原生表单与触屏仍待试玩。官方参考已下载并索引，无运行依赖或地图/美术变化。

## 第三十六轮：查找已读原文并收起长物证库

手记与选证库可手动按已记地点、标题或原文筛选，地点只来自实际记录；结果计数不判断物证相关性。输入控件保持原位，新开页面重置显示范围，空结果可清除。筛选不改变已选物证、解释、草稿或完成条件，对照区继续显示所选原文，可换掉当前列表中隐藏的卡。

物证库用原生 details 手动折叠；恢复两份选证的草稿时默认收起，换证/清空草稿会展开。原生 label、焦点与 Tab 范围沿用，结果使用 status 提示，不新增全局键盘监听或存档字段。既有玩法检查覆盖发现边界、原文查询、清除、输入焦点、隐藏选证/提交与草稿展开；真实原生折叠和触屏布局仍待试玩。

## 第三十五轮：读完与推理完成后自主回返

学校最后试卷和医院缴费单先展示原文，由玩家选择对照已读物证、暂回或继续观察。正确提交后的结论读完回到记录旁，已完成重读也不会自动回宅；可以回看手记判断，或明确选择回返。追逐恢复提示与原切图流程保留，未提交仍只是草稿。

两份原对白迁为同源文书并记录地点，正文、物证、贴图、坐标和完成条件保持。实际工厂/交互检查覆盖阅读与选证分开、原文去重、成功不自动离场、完成后重读/停留/查看判断、明确回返与追逐状态、安全记忆存档。真实阅读衔接和触屏仍待试玩，布局和素材未改。

## 第三十四轮：让事故现场和两条去路相符

回宅入口从东侧移回西侧，山路仍在东侧，已拼合后的目标和主动提示明确方向。护栏断口放到车头前，连续护栏、路面标线与车后刹车痕构成事故位置；三张新纹理沿用现有像素配方。完整护栏与事故车有碰撞，断口与去向仍主动调查，原物证、原文、答案和确认条件不变。

沿用 furnishings 的旧落点保护，只修正和新碰撞重叠的位置。现有角色可达/实际焦点、物理偏移和恢复检查扩到事故图；从真实物件与两个去向核对未证明不选结局、提交不自动离场、取消保留选择、明确确认才到餐桌或归路。

[事故布局预览](previews/crash-scene-v1.png) 与素材表已生成并目视检查，脚本新增 -CrashScene 模式。图中墙体简绘、无游戏光照与镜头，实际可见度、绕车手感和触屏仍待试玩。

## 第三十三轮：让学校与医院具有可走的场所结构

学校用四套课桌椅、讲台和侧窗形成中央及桌间路线，成绩单和最后试卷回到桌面；医院用候诊长椅、屏风、床头柜与票据桌分出候诊和病区，原病床加入家具碰撞。九张新纹理走原像素配方，物证坐标、原文、推理与回返保持。背景家具不注册调查，不增加清单或线索计数。

地图 furnishings 可设置相对图像左上角的 collision，普通调查物也可附带碰撞。家具加入原静态组并同步实际尺寸/偏移；纸张保持桌面上层。只在这两处布置地图检查入场位置，旧存档若与新家具重叠，退到本房最近可站格，合法位置不动；safeStart 使用修正后的实际位置。官方 API 参考见参考索引，不引入引擎更新。

地图与玩法检查核对素材、脚印范围、8px 步长的角色可达/实际焦点、桌面层级与旧位置恢复。素材表及 [布局预览](previews/memory-rooms-v1.png) 已重建并目视核对；预览墙体简绘，没有游戏光照、镜头或角色，实际遮挡和触控手感仍待试玩。

## 第三十二轮：合上手记后保留推理草稿

每段推理分别保留当前选证和解释，重开、换房、安全存档或被抓知识恢复后可继续整理；手记标为未提交草稿。原文对照、选中态与解释一起恢复，仍需主动提交并通过原验证才完成。成功清除该事件草稿，也可主动清空后重新选证，其他事件与已读记录保留。

草稿仅恢复至多两份已收集物证，去重并过滤失效解释；解释按文字保存，避免选项顺序变化时误选。未知事件不因草稿提前显示，旧存档没有草稿即从空白开始。沿用原安全存档规则，不在追逐/躲藏中覆盖安全记录。现有玩法检查覆盖三段完整往返、存档恢复、补证后提交、过滤与清空、被抓保留，实际阅读与触屏仍待试玩。

## 第三十一轮：发现线索后即可提出假说

手记不再自动显示指定相关物证的计数，也不以两份正确物证齐备作为打开推理页的条件。发现任一该事件记录便可开始选证与解释；学校最后试卷、医院母亲回声同样能引出问题。选证只列实际已发现的记录，提交仍严格核对原来的两份物证和解释，尝试、取消或猜对解释都不自动完成。

问题改成中性提问，不在开头替玩家断定学校没有处分、事故已经过去十年；原文、结论、完成条件与主动提示保留。没有增加草稿或存档字段，未见过的事件仍隐藏。玩法检查覆盖提前尝试、无关材料失败、未读记录不可选、取消/存档边界，以及从实际最后物件先引出问题。入口同步，真实推理难度与触屏仍待试玩。

## 第三十轮：让搜集与守灯交替推进

供桌不再要求四种材料全部齐备才开放操作。可先摆饭，找到香和火柴后点香烛，再去取纸钱；缺材料只反馈，不重置供物。有材料但错序仍免费重试，三步完成才松门闩和中圈红线。沿用原材料字段、ritualStep、供物表现与存档，没有新增收集任务。

按钮不再按正确步骤排列，器物位置保持。纸条只有实际已读才从手记原文展开回查，未读时仅指出桌边有纸，不自动补全文或增加必须阅读的门槛。门闩描述、供桌状态、HUD 和主动提示同步部分进度；原本地房间提示优先级保留。

现有玩法检查覆盖真实供桌回调、无材料限制、部分供物与存档、未读边界/已读回查、缺料不重置、错序重置、离桌续做与最终解锁。脚本和语法检查通过，入口同步；实际节奏、观察难度和触屏仍待试玩。

## 第二十九轮：声音边界与可选麦克风释放

空间声在 600 像素边缘或范围外不创建节点，避免零音量指数渐变；非法源坐标也略过。没有立体声节点时使用普通音量衰减。Web Audio 不可用允许静音游玩，恢复被拒绝不阻断开始，标题继续时会重试现有声音管理器。

重复开启麦克风共用待批准请求，完整建链后才启用；取消或离场后返回的旧流会停止，失败释放节点并允许重试。关闭声控清空全部引用。旧暂停页的异步结果只更新原页，不覆盖后来的阅读内容或停止新场景的流。浏览器权限窗口本身不能由游戏撤回，声控仍自愿开启。

玩法、恐怖节奏和启动路由行为检查通过，入口同步。音频与权限使用模拟节点检查，没有调用真实设备；实际声音、设备兼容、权限窗口和触屏仍待试玩。

## 第二十八轮：对应门口的入房落点

修正大门进正厅、正厅进地下室、地下室回正厅、暗室回卧室和阁楼回走廊五处落点。分别对应目标房间的南门、东门、西门、衣柜旁暗门和走廊东侧入口，避免地下室直接落入迷宫深处、阁楼回程偏向后院。房门、房间连接、格子和物件保持原状，原锁定条件不变；旧存档落点不强迁移。

一次性几何核对经实际 Player 构造与 MapManager 衣柜工厂，检查 24 个双向门落点的地面、距反向门范围、门触发区与暗室回程衣柜避让。地图、玩法和模块语法检查通过，入口同步；不为可逆坐标调整新增镜像测试。真实连续切图和移动手感仍待试玩。

## 第二十七轮：明确确认后重新开始

有继续记录时，标题的“重新开始”先显示原生 dialog，说明会清除调查与手记，默认聚焦保留进度。确认期间标题按钮、Enter 和空格不能穿透；取消或 Esc 保留旧记录，明确清除后才调用原开始逻辑。旧浏览器使用原生 confirm 回退，无新依赖。

旧面板回调与重复确认不重做动作；离开标题移除其键盘处理和未完成面板。现有启动路由检查扩展为真实标题回调检查，覆盖取消、确认、继续、背景输入、重复键、首次开始与清理；启动路由、入口及修改文件语法检查通过，入口同步。真实原生遮罩、焦点、读屏和触屏仍待验收。

## 第二十六轮：失误后保留已经学到的内容

被抓仍回到本房间入口，物品、家具、守灯操作与理智按原入房快照恢复；已读原文、来源、路线、观察标记和已提交推理保留。recoverFromCapture() 深拷贝处理，不改写输入快照，不把材料齐全等同于完成，也不让已知路线绕过恢复后的门锁。恢复状态先写安全存档再重启，清除本次追逐与躲藏，重入提示一次。

安全暂停退出改为“保存并返回标题”，主动写最新状态；追逐/躲藏仍用上次安全记录，按钮明确说明。记忆中暂避的外部追逐仍按原规则保存。无新存档字段，旧存档继续使用。

玩法检查覆盖事实保留与物理恢复、未提交、锁定路线、重复计数和四种标题退出；恐怖节奏检查通过真实捕获回应与重启路径核对恢复时机、持久化及不重复死亡。玩法、恐怖节奏、入口和修改文件语法检查通过，入口同步。真实切图、恢复提示与存储体验仍待浏览器试玩。

## 第二十五轮：阅读层内的键盘焦点

手记、路线、提示与解谜层的 Tab/Shift+Tab 保持在可用控件间，首尾循环；隐藏、禁用和负 tabindex 控件不进入循环，内部顺序交给浏览器，保留浏览器切换快捷键。页面打开/替换时从标题与顶部开始，保险箱继续聚焦其数字键盘。

返回点只在从游戏打开首层时记录，换页不覆盖；Esc 或关闭返回仍存在的入口，入口已移除时回退手记按钮。既有暂停/恢复及输入处理不变，无新监听或存档字段。对照 W3C 模态对话框模式，原文与许可见 [参考索引](references/README.md)。

玩法检查运行真实模态生命周期和键盘处理，覆盖循环、空页、重复键、可见性过滤、换页与返回；玩法、入口及修改文件语法检查通过。轻量 DOM 只提供布局表面，真实浏览器的原生 Tab、滚动与读屏行为仍待验收。

## 第二十四轮：能保留下来的暗室与地下室记录

暗室木偶笔记与红字、地下室抓痕与两份纸条改用现有文书交互，补稳定 id、标题与原文，保持位置和内容。纸页用 document_page，红字/抓痕用 scratch；实际阅读才留在手记并记录地点，既有去重、路线回查和存档适用。没有新增核心物证或结局计数，也不补未读内容。

五处记录经真实工厂、地面接近点、焦点与阅读检查，核对来源、去重、存档保留及不增加真相计数。墙面读物保留原位，目标墙格可调查，中间墙仍会挡住交互。地图、玩法、入口和修改文件语法检查通过，入口同步；无新素材，不重建预览。实际辨识与阅读密度仍待试玩。

## 第二十三轮：跟随当前调查的主动提示

三级提示优先照顾当前房间未完成的供品和学校/医院调查，再回退全局目标。父母卧室按衣柜是否挪开区分，暗室直接提示工作台；后院取香后可提示井钩。两份记忆物证已齐时指向手记对照与提交，守灯中途提示剩余步骤。危险和记忆空间继续优先，默认 HUD 不变。

分级按实际物件/物证进度区分上下文，沿用原 hints 字典；索取提示不会替玩家收集、完成或移动。既有玩法检查覆盖房间优先、状态变化后分级、完成后回退、续步与危险优先，并核对无额外发现。玩法、入口和修改文件语法检查通过，入口同步；方向是否自然与具体程度仍需实玩反馈。

## 第二十二轮：认得出的终章去处

事故记忆的两处去处从染色地砖改为 mountain_path（96×64，路标与湿石阶）和 manor_threshold（80×64，旧门楣、门缝灯光与垂下红线）。近处分别显示“通向山路的石阶”和“回到老宅的门口”，保留原 id、坐标、对白与 endingChoice，不加入家具碰撞或自动切图；调查范围按各自外形提供。推理与确认流程不变，素材不标注结局好坏。

既有地图、玩法、入口和修改模块语法检查通过，入口与联系表已同步，预览已目视检查。本轮无新机制，不新增镜像测试；实际光照、比例与触屏范围仍待试玩。

## 第二十一轮：能观察到完成后果的棺上红线

三圈红线分别随学校推理、完成守灯、医院推理松开，独立旧锁仍需红钥匙。coffinTexture() 只用原 deductions 和 candlesLit 派生八种同为 64×128 的外形；创建、重入/读档，以及正厅内提交推理和完成守灯时同步，不增状态或修改原开棺条件。线结绘在符纸上方，避免中圈变化被盖住。

棺边可主动记下锁与纸片的实际状态、尝试开盖或离开。缺钥匙、中圈或上下死结分别反馈；观察不加真相物证，不提前公开棺内内容。满足条件后仍需确认进入最后记忆，取消不推进；确认才记录原物证，读完锁舌回应后沿既有终章入口继续，旧两秒锯齿低音改为短锁声。

行为检查覆盖八种组合的真实工厂/焦点/记录、存档恢复、失败与取消、单次确认和回应时机；原推理与仪式检查验证即时松线且未提交/未完成不松。玩法、地图、入口及修改文件语法检查通过，联系表已重建并目视检查。真实光照、痕迹辨识和确认操作仍待浏览器试玩。

## 第二十轮：需要互相对照的年份残字

家规背面保留“结婚那年，一九□□”，湿纸条保留同句的“□□八八”，分别说明末尾潮斑与开头水洇；家规物证名去掉完整年份。原密码与钥匙逻辑保留，仍允许直接猜对，不把读齐两份记录设为开锁条件。

锁旁通过 getJournalEntries() 展开已读相关原文，可直接对照，不替玩家拼成年份或填入数字。旧存档里已记下的完整年份也保留回查；未发现材料不补，原文按现有规则去重和显示地点。其他手记展开方式不变，无新增物件、美术或存档字段。

现有玩法检查覆盖两份材料的未读/单份/双份边界、展开与去重、旧完整原文保留，以及无线索也能猜中；原输入与取消检查继续通过。玩法、地图、入口及修改文件语法检查通过，入口已同步。实际排版、触屏和难度尚待试玩。

## 第十九轮：接通卧室日记与衣柜调查

旧卧室日记和衣柜原定义只有坐标，没有满足工厂的交互注册条件。新增 mother_diary / my_cabinet 稳定 id 与名称。日记使用原 16×20 纹理，作为非家具的调查图片画在桌面上方，移除其单独的家具碰撞；衣柜保持原位，接入既有躲藏行为。

## 第四轮：预警、间隔与声音来源

参考 Frictional Games 官方设计文章并复用现有工程，移除普通探索的随机压暗、抖屏和密集静电噪声，改为有间隔的实际物件声：厨房滴水、木板轻响、阁楼纸钱等。声音从地图对应物件位置发出，并有短文字提示；阅读、追逐和记忆调查期间停止普通环境提示，追逐结束后留出恢复间隔。日记阅读不再触发三秒抖屏。

追逐者改用独立的阴影纹理。生成点必须在玩家可达区域、避开家具与树，并与玩家至少间隔 192 像素；空间不足时等待重试。首次出现和跨房跟来均先给 1.8 秒活动时间的轮廓与脚步预警，阅读、暂停和切图不消耗该时间。脚步有实际方位与距离衰减，文字也反馈方位，降低红色覆盖和心跳强度。记忆中不生成外部追逐者，追逐状态保留，回宅后带预警恢复；记忆检查点可保存这段待恢复状态。

理智改用每秒计量，普通高压房间下降 0.4/秒、近处追逐 0.9/秒，未被追逐时旧卧室恢复 2/秒，记忆恢复 1/秒；取消低理智时按帧随机惊吓。可选麦克风的暴露也按活动时间累计，阅读时暂停，避免计时器穿过手记触发对白。

新增 `verify_horror_pacing.mjs` 调用真实场景方法，验证可达生成、预警不可捕获、阅读冻结预警/脚步/麦克风、记忆避险与回返恢复、存档保留待恢复追逐、30/60 FPS 理智一致、环境声来源和追逐后的安静间隔。已取走的香与纸钱不再换房后重新创建，纸钱取走后也停止对应环境声。六项行为/入口/地图等检查通过；实际视觉、空间声像听感和难度仍须浏览器试玩，脚本不能证明它们已经好玩。主入口已重建，3D 与源美术未改。

## 第三轮：探索记忆与调查反馈

手记新增“走过的路”，可按 M 打开，仅记下实际到过的房间与穿过的门。选已知房间后，按当前门锁状态给出路线和下一扇门的方向，不直接移动玩家；记忆单独记录，不成为空间捷径。旧存档不会凭空补全探索图，后续走过的通路会继续记录。

近处物件新增焦点角标与调查状态，区分看过、变化、未完成操作和躲藏用途；读对白及换房等状态清理旧焦点，躲藏退出提示单独维持。距离选择不再让 NPC 强占近处物证；墙体会阻挡隔墙交互，壁面物件仍可调查。卧室日记删除直接宣告十年前车祸死亡的文字，保留可供对照的家庭生活记录。

新增行为覆盖已走路线与门锁、未知房间隐藏、记忆无虚构捷径、变化照片与未完成推理、NPC 焦点与对白清理、前期日记的信息边界。入口、玩法、地图、状态、路由检查通过；更新已写入 `index.html`。仍需实际浏览器验收地图可读性、角标层级和触控，不把轻量 DOM 检查当成截图或实玩结果。
