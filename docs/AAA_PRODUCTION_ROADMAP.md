# 《回煞》3A 视觉线生产路线图

## 目标边界

本路线把 `aaa3d.html` 作为独立的高画质纵切片，不覆盖现有 2D 主线和 `prototype3d.html` 基线。视觉目标是吸收现代写实、电影化 3A 游戏的通用制作标准：可信材质、清晰空间、受控曝光、叙事细节、稳定帧时间和可复测的画面完整性；不复制任何具体商业作品的角色、武器、场景、标志或专有资产。

单个 WebGL 页面、程序化几何和现有概念图无法等价于大型工作室的完整资产管线。当前完成的是可运行的视觉基线与验收闭环；达到真正发布级画面仍需要建模、扫描/PBR 贴图、动画、VFX、声音、性能与大量内容生产。

## 循环迭代闭环

每一项视觉工作固定经过“基线截图 → 单变量改造 → 同机位截图 → 匿名 A/B → 独立评分 → 问题回灌 → 回归验证”。总分增长不是唯一门槛：任何一票否决、可读性下降、明显穿帮或帧时间失控都必须回退处理。每轮至少保留默认广角、英雄道具近景、最暗路径和斜角厚度四类样本，避免只优化一张英雄截图。

`tools/build_visual_blind_test.mjs` 负责把输入图随机映射为 A/B；评审者不得读取 `.answer.json`，必须先完成 `docs/AAA_VISUAL_QA.md` 的评分记录。与外部作品对比时，应由老板提供拥有合法使用或评审权限的同规格截图，系统只做匿名并排与评分，不从第三方游戏复制资产。

## 当前最高优先级

Build 03 经过两轮专项匿名复测：第一轮以 60.8 对 55.3 明确胜出，第二轮再以 68.8 对 60.8 明确胜出；固定 `corridor`、`doorLock`、`doorCrack` 三机位均无 P0/P1，V3 可以带 P2 债务退出。通过项包括六块退入门框的实体门板、暗腔内断续门缝、同轴地面漏光、横木包覆卡座、合页铰轴、带座门环、有卷曲/印记/固定点的封条、统一哑光木材和近门手电曝光衰减。下一阶段进入 V4 动态与 VFX，但需继续携带门缝边缘红色反弹、符纸微表面、横木/卡座/门环磨损、门体与墙面细节频率以及近景左侧死黑等 P2；同时，V2 遗留的棺材材质、红绳压重、供品基础几何和地面硬边污迹仍未自动消失。当前分数只代表固定静帧纵切片，不等于发布级 3A。
