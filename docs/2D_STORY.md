# 《回煞》2D 调查篇：剧情与玩法

更新：2026-11-16。本文对应本轮实现；`STORY.md` 的长篇小说保留为原始素材，不再作为当前流程契约。

## 故事的因果

李明收到一封无署名的信，在七月十四的雨夜回到旧宅。车门关着，人却已经站在车外，这是第一个矛盾。供桌上摆着父亲的遗像，信封却写着“李明收”。棺材里的声音模仿父亲，试图让他继续服从。

公路上的车没有冒烟或当场碰撞。玩家可调查紧闭的车门，记下左后门浅色的月牙划痕；事故记忆中的同一划痕已经锈进铁皮。来信写明东西留在供桌右侧黑布下面，这个具体目标由阅读后获得；未读信也能自由进宅。大门只有旧刻痕门柱，不再重复摆放另一辆同款车。

十年前，李明因禁闭和长期控制离家，在路上遭遇车祸，未能从车里生还。学校的成绩单和黑板揭示控制，医院的窗口和病床揭示被阻断的求助。母亲需要的是治疗和支持，孩子不需要为她的病情承担责任。旧宅是这些未能说清的记忆的交汇，雨夜重演不是新发生的第二场事故。

开棺得到的是校服和李明自己的名字。事故现场保留着扣紧的安全带、十年前的事故编号和纸飞机。这些实际可调查的物证构成第三段推理的依据，避免只靠独白直接宣布反转。

## 玩家实际做什么

开场两段对白按阅读回调推进，可按 Esc 跳过。进宅后，靠近物件显示名称和 E 提示。黑布与供桌分开放置，防止供桌一直抢走黑布交互。守灯纸条把供品位置和仪式规则留给玩家，也会保存在 J 手记。

相框先保持盖布外形，查看布角只能认出露出的“收”字，可记下观察或暂时离开；不在揭开前公开父亲遗像和完整名字。主动揭开才显示遗像、读到背面“李明收”、收记守灯纸条并触发南门门闩。外形由历史状态随换房和存档恢复，已揭后可分别回查原文，不重复关门，也不会重新封住已完成守灯的南门。纸条阅读与手记共用同一原文。

公路与大门不再用进场延时弹对白，信、车辆和门柱都可主动调查回看。这些观察补充去向和对应关系，不计入真相线索数量，也不成为强制停留任务。

厨房取得饭，父母卧室调查家规和保险箱，推开衣柜进暗室拿火柴，后院取香，阁楼取纸钱。正厅原有土堆与灶台的重复取物捷径退出主线，避免提示和实际产出不一致。仪式要求依次摆饭、点香烛、焚纸，可以先用已有材料做一段，再去找余下材料；缺材料时不执行动作、不清掉已摆的供物。有材料但顺序做错会熄火并提示重试，不扣供品。三步完成后，南门恢复可用。

厨房橱柜能看见留着的饭碗，暗室工作台的刻刀旁放着火柴。调查后可主动拿走，也可先留在原处；取消不改变背包。拿走后立即留下碗印或浅方印，换房与存档继续保持。两处仍沿用原有供品状态，不增加工具或推理门槛，暗室笔记仍可调查。

衣柜需要主动选择挪动，查看柜脚会发现向左的一掌宽擦痕和紧贴东墙的右脚；记录可在手记回查。可以先观察，也可直接尝试，向右推不动。玩家退开柜脚将经过的位置后，向左挪开衣柜，暗门和门牌当场显露；只在挪动完成后开放通路。

保险箱锁旁刻着“结婚那年”。家规背面与湿纸条分别留下年份前、后两位残字，可按同一句题字对照。已发现的相关原文在锁旁展开，未发现记录不显示，也不会自动拼年或填数。仍允许直接猜对，不要求先读齐材料；输入四位后主动转动锁钮，错误可以修正或暂时离开，正确提交获得地下室钥匙，箱门保持打开。旧存档记下过的完整年份仍可回查。

守灯每一步都会改变供桌：饭碗、香与烛火、纸灰依次出现。中途离桌或查看手记保留进度，换房和安全存档也能恢复；顺序做错会收回供品并重置。第二步虽然已有烛火，南门仍扣着，第三步焚纸完成才算仪式结束并松开门闩。

供桌动作不按答案顺序排列，摆饭需要饭，点香需要香和火柴，焚纸需要纸钱；材料未找到不能凭空操作。纸条只有实际读过才在仪式界面展开已记原文，未读时只说明桌边夹着纸，不自动给出全文；仍允许依据自己的判断直接尝试，不设阅读门槛。供桌调查状态、目标和主动提示支持分段进行。

旧书房的桌下旧书包、药柜小间底层的排号单分别通向学校和医院记忆。入口观察先记入手记，由玩家选择是否进入；取消仍可留在旧宅继续探索。记忆中可从暂停或拼合界面暂回原房间，保留已读物证；未提交的判断不算完成，之后能从原物件重访。外部追逐若仍存在，暂回按钮会说明其将恢复，回宅后保留原有预警。这个返回方式不适用于终章事故或餐桌。

学校最后一张试卷与医院灯下的缴费单先展示并记录原文，不立即打开选证页。可以主动对照物证、继续观察或暂回；正确提交后读完结论，仍回到记录旁，由玩家决定何时离开。已完成后重读也只展示记录，并可回看手记判断；明确选择回到旧书房/药柜小间才切图。两份记录保留来源并与物证卡按正文去重，反复阅读不增加真相计数。

玩家需要调查两件具体物证，在最终物件或手记中选出两份记录、选择解释，再提交判断。学校核对黑板与成绩单上的禁足笔迹，医院对照同日求助与家属拒绝住院的先后。错选物证、猜错和取消都不会完成记忆；正确提交才同步推理与学校/医院完成状态，回到旧宅后也可在手记提交，不必重访最后物件。手记只显示已发现的事件，记录原文可展开回看；需要帮助时主动索取三级提示。

发现事件的一份记录就能尝试解释，学校最后试卷与医院母亲回声也能先引出问题。手记不自动报告找到几份指定“相关物证”，玩家自行判断哪些已读记录可共同支持解释；物证未齐仍能尝试，但不能凭正确解释完成。问题以中性方式提问，未读记录不会加入选证区，未见事件仍隐藏。关闭后本次选证与解释留作该事件的未提交草稿，回现场找新线索后可继续整理；草稿随安全存档与被抓知识恢复保留，重开不会自动提交或完成。

手记会标出未提交草稿，可直接继续原文对照与解释。可以清空当前事件重新选证，已读记录和其他事件草稿保留；判断正确提交后才清掉该草稿。恢复时只采用仍有效的解释与已读物证，至多两份且不重复。旧存档无草稿则从空白开始，草稿本身不会揭露未见事件。

拼合界面把两份已选原文与来源放在解释选项上方，便于直接对照，可换掉其中一份并保留当前解释。学校引导核对书写者与禁足决定，医院核对时间与家属签字，事故核对姓名、编号年岁与安全带痕迹；失败后提供相同的阅读方向，不替玩家逐份判对错。未选或未发现的记录不会自动加入对照。

手记与选证库可手动按已记地点或标题/地点/原文查找，地点选项只来自实际读过的记录。筛选只缩小列表显示范围，已选物证与解释继续留在对照区，不自动挑相关卡；无结果可清除，新开页面从全部记录开始。物证库可收起，已有两份选证的草稿默认先看对照与解释，换证或清空草稿时展开物证库。

主动索取提示时，先照顾当前房间未完成的调查：例如阁楼纸钱、暗室火柴或药柜小间的医院记录，再回到全局目标。衣柜已移开、物证已读齐和守灯中途各有对应提示，不要求重复操作或重访最后物件。追逐、躲藏和记忆中的提示仍优先，索取提示本身不增加物证或完成状态。

手记、路线与解谜界面支持 Tab/Shift+Tab 在当前层内选择控件，Esc 合上。页面替换时从标题与顶部开始，关闭后返回最初打开它的位置，避免换页后把焦点留给已移除的按钮。保险箱仍可直接使用数字键盘输入。

阅读层打开时游戏键盘暂时让位给原生控件，WASD/空格用于文字输入，方向键用于光标或下拉选择；关闭后清按键并恢复原游戏设置。中文输入法组字中的确认/取消键留给输入法。手记表单中的空格/回车不推进隐藏对白，文书与可见对白仍沿用原关闭/推进规则。

记忆里的关键物证各有对应外形：学校的黑板排名与红笔成绩单、医院的玻璃诊室窗口和挂着留床单的空病床、事故现场的断裂护栏与外侧纸飞机。画面提示可以调查的物件及其痕迹，完整文字仍在原文阅读和手记中；没有因美术变化增加收集步骤或改变答案。

学校有课桌排、讲台与侧窗，成绩单和最后试卷落在课桌上，中央与桌间可以通行。医院有候诊长椅、分隔病区的屏风、床头柜与票据桌，缴费单放在桌面。落地家具和原病床具有实际碰撞，侧窗只作墙面表现；背景物件不新增调查任务或物证。两处旧存档若恰在新增家具内，会在同房最近空地恢复，合法落点保持，调查与草稿不丢失。

走廊第三张旧照会显出被遮住的人物和相纸文字，药柜小间门外会出现复诊封套，分别由学校/医院记忆正确拼合触发。若站在走廊里提交判断，当场更新这些物件；若在别处完成，进入走廊时按状态恢复。变化仍需主动调查，不用强制对白替玩家宣布，不会自动读入手记，也不会增加核心物证数量或改变通路。

手记里的“走过的路”（M）只标出已到房间与实际穿过的门，可对照门锁状态回想路线；记忆不按实体房间连接。物件近处显示焦点和调查状态，读过的旧照变动后会提示“有变化”；读过最终物件但未解推理仍显示“待拼合”。前期卧室日记只提供母亲的生活记录与未寄出的信，避免提前宣告事故的年代和死者身份。

实体房门的入房落点对应目标门口：地下室从东侧入口附近起步，回正厅落在西门内；阁楼回到走廊东侧，暗室回到已挪衣柜下侧的空位。房间连接与门锁条件保持，落点避开反向门触发区，便于辨认刚走过的方向。

旧卧室日记位于书桌上层，可从近处调查，原文保留到物证卡与手记并记下来源；同一页不会重复列为两条记录。日记不作为家具阻挡移动。同屋衣柜可直接用于躲藏，沿用床与普通衣柜的脱身规则。

新观察会记下发现地点。展开手记记录，可回想去已到实体房间的路线；路线图选中房间，也能回查在那里记下的文字。显示只来自已收集物证和已读观察，不列出未知物件或替玩家判定已查遍。旧记录未记地点时继续保留原文，实际重读后再补来源；来源信息不补出未走过的通路，记忆中的记录也不会成为实体捷径。

暗室的木偶笔记和红字、地下室抓痕与两份藏起的纸条，读过后也会留在手记并标出地点，便于回查家人当时的说法。它们属于原有环境观察，不增加核心物证或结局计数；未读内容不会自动记入。

走廊窗户有可见的横木、窗扣与抓痕。调查时可辨认屋内窗扣已经拨开，阻挡来自窗外木板与钉子；这份观察记入手记，可按走廊来源回查。仍沿用原有控制类物证，不新增开窗工具、出口或通关门槛。

井口仍由石板与符纸封住，红钥匙挂在井外侧铁钩上。观察钩尖和锈层亮痕可记入手记，提示抬高钥匙环再向井外移；径直向下拉只会被挡住，不扣资源或触发危险。可自行猜对，不强制先读观察，也不需要搬石板或找工具。取走后钥匙从画面消失，安全存档和重入按已有状态恢复空钩。

有效动作后仍明确预告追逐和躲藏规则，由玩家确认才取得钥匙；读完取得回应后启动追逐预警。奔跑真正增加速度，体力按时间消耗。追逐者使用地图网格绕行，生成点避开墙和家具。床和普通衣柜提供躲藏，保持安静累计 6 秒可以结束本次追逐。声控躲藏由暂停菜单自愿开启；没有麦克风仍能通关。

声音不可用时仍可静音探索。声控申请去重，离场会取消待批准申请并释放已有音轨；旧权限结果不会覆盖后来阅读的页面或停止新场景的声控。浏览器权限窗口不能由游戏撤回，过期申请获批后会立即停止其流。

被抓回到本房间检查点，物品、家具、守灯操作和理智仍按入房时恢复，已读文字、路线和已提交判断保留。材料已找到但未提交不会算作完成，记得暗门也不能穿过恢复后关闭的衣柜。恢复后清除本次追逐并保存，不会陷入同一追逐的连续死亡。

黑影出现时先有轮廓和方位脚步，1.8 秒活动时间后才进入追逐，生成点距玩家至少 192 像素并位于可达区域；读对白、暂停和切图不消耗预警。记忆空间暂停外部追逐，状态保留到回宅后再带预警恢复。普通探索声来自实际物件，追逐和记忆中停止；低理智不再触发按帧随机抖屏，也不会再随机把整个房间压暗。

## 收束与结局

棺上的三圈红线分别随学校推理、完成守灯与医院推理松开，金属旧锁独立存在。可在棺边观察并记录纸片与线结的实际状态，条件不足会指出锁、中圈或上下死结；观察不增加真相物证。外形按完成状态即时更新并随重入、存档恢复，未提交的判断和只有烛火的仪式第二步不算松结。

仪式、钥匙与学校/医院的两段推理完成后，仍由玩家确认开棺，读完锁舌回应才进入事故记忆；可以取消并继续调查老宅。事故物证拼合完成后，走向山路或回到老宅的选择都需要确认。回到餐桌还有一次拒绝留下的机会；选择留下再次确认，不再自动替玩家答应父亲。

事故记忆的两个去处分别呈现为路标旁的石阶、亮着门缝灯光的老宅门口，近处有对应调查名称。靠近不会自动切图或替玩家选择；仍先调查，再经过原有的推理与确认流程。

山路位于东侧，回宅门口位于西侧来路，已拼合后的目标也按东西指向。撞坏的车头靠近连续护栏的断口，车后有刹车痕和磨损路面标线；完整护栏与车体阻挡移动，保留通往两份物证及两个去向的绕行路线。背景不增加收集，原车门与护栏文字、答案和结局条件保持；旧存档若落在新增碰撞内，仅就近恢复到本房空地。

“破茧”是低线索时主动离开，“回煞”是了解家庭创伤却未认清死亡时离开，“归路”是认清事故后自己走出去，“永远在一起”是明确选择留在循环。留下结局呈现红线重新收紧，不把控制或死亡包装成修复关系的办法。

## 交付边界

本轮仍是原有 Phaser 2D 工程，未新增 3D 内容；角色、纸人与主要家具由本地像素纹理增强，未将旧 3D 素材贴进地图。安全房间自动存档，标题可继续。安全状态从暂停返回标题前会主动保存最新记录；追逐或躲藏时继续使用上次安全记录，记忆暂避仍按原规则保留外部追逐。浏览器禁用存储不影响当次游玩。`index.html` 是同步生成后的直开入口。

标题选择“重新开始”后会先确认清除调查与手记，默认保留记录；取消或 Esc 返回标题，只有明确选择清除才重开。确认期间 Enter/空格不会启动背景中的继续按钮。

状态和交互契约可以由脚本验证；视觉布局、触控手感、完整通关时长和追逐强度仍需要实际浏览器试玩，不能用静态验证代替。
