# 回煞 2D (Return of the Soul)

## 2D 已停止研发（2026-11-16）

老板已决定停止 2D、重新制作 3D。本仓库保留 2D 第三十七轮成果及其历史，不再扩展玩法。[全新 3D 版本使用独立仓库](https://github.com/huachen19867/huisha_game_3d)，本地项目在 `huisha-3d/`，双击其中的 `StartGame.bat` 可启动。两边有独立入口、源码、存档和 Git 历史，不混传运行文件。

旧 3D 原型与源美术原件仅在本地保留，已从本仓库发布范围移出，没有删除本地文件。版本对应关系见 [版本与仓库说明](docs/VERSION_LAYOUT.md)。下方为封存时的 2D 说明，历史段落不代表当前研发方向。

> **“门一直开着。你却走了十年，才走到门口。”**

## 当前版本：2D 调查篇（2026-11-16）

这一版集中改造 2D 主线。调查手记（J）只记录已发现事件，三段推理需要选出物证、选择解释后提交；新增主动请求的三级提示，记忆回返会改变走廊旧照并留下可调查文书。守灯仪式按顺序操作，结局由玩家确认。奔跑、体力、躲藏脱身、安全存档和场景切换时的触控监听也做了修正。角色与主要家具使用增强后的本地像素纹理，室内不再下雨，出口有中文门牌。

发现事件线索就能尝试推理，手记不再自动筛选并统计哪些记录与答案相关。可以先提出假说再回现场观察，选证与解释会留作未提交草稿，随安全存档保留，也可主动清空重选。只有提交的两份物证与解释成立才完成记忆，未读记录不会加入选证。

手记和选证库支持按已记地点或原文文字查找，筛选时保留已选对照与解释。长物证库可以收起；恢复两份选证的草稿时，先看到正在整理的原文。

阅读层会把键盘交给文本框、下拉和按钮，合上后恢复游戏操作；中文输入法组字时保留其确认与取消操作。

学校和医院的最后记录可单独阅读，再主动对照物证。推理完成后可以留下继续观察或回看判断，明确选择回宅才离开；重读也不会自动把人送走。

追逐前有轮廓与方位脚步预警，阅读会暂停预警；进入记忆暂避外部追逐，回宅后恢复。普通探索的声音来自滴水、木板、纸钱等物件，取消了随机压暗与低理智抖屏。实际难度和视听表现仍待浏览器试玩验收。

声音不可用时可静音继续，不支持立体声节点时保留距离衰减。可选声控的重复申请会合并，离场后才返回的旧申请会释放音轨，避免干扰新场景；真实设备与权限窗口仍待试玩核对。

标题使用新生成的雨夜老宅 2D 插画，显示上次停留房间与基础操作。图片内嵌在入口中，解码完成后进入标题，失败时回退原简绘。资源来源与完整提示词见 [2D 美术资源说明](assets/2d/README.md)。

厨房、盥洗间、地下室及学校/医院记忆采用不同地面材质。病历、香、纸钱和钥匙有独立外形，普通装饰使用固定位置的暗色磨痕，减少与物证混淆。可查看 [像素素材预览](docs/previews/README.md)，其中不包含游戏光照效果。

学校补上课桌排、讲台与侧窗，医院补上候诊座椅、屏风和床头柜，纸张放在桌面上。落地家具具有碰撞，并保留通向各物证的路线；可查看 [记忆房间布局预览](docs/previews/memory-rooms-v1.png)，墙体为简绘，非游戏截图。

事故现场补上连续护栏、路面标线和刹车痕，车头对应断口；西侧回宅、东侧走向山路。车辆和完整护栏有碰撞，去向仍需主动确认。可查看 [事故布局预览](docs/previews/crash-scene-v1.png)，不包含游戏光照和镜头。

守灯操作会在供桌留下饭碗、香烛和纸灰。已有材料可以先做一段，再去找剩下的；缺材料不重置供物，已读纸条可在桌边回查。中途查看手记或离开房间可继续，进度随安全存档保存；三步全部完成才松开南门，错误顺序可免费重试。

保险箱支持数字键和触屏输入，Backspace 修改、Delete 清空、Enter 确认、Esc 离开。家规背面与湿纸条留下年份前、后两位残字，已读原文可在锁旁展开对照，仍允许直接猜对开锁；旧存档记下的完整年份保留回查。开锁后显示打开的箱门，钥匙随背包保存。

开场可主动调查来信、车门和门柱，读信后得到更具体的去向；车辆划痕可以和后来的现场对照。观察记入手记，直接进宅也可继续，不再被进场延时对白打断。

父母卧室可先观察柜脚擦痕，再决定挪动方向；衣柜不会在读完对白后自动移动。挪开后暗门即时显露，观察记录与开门状态都可保留。

井边可观察钩尖与亮痕，再选择取钥匙的动作。拉错可重试，拿走前仍明确确认追逐风险；钥匙取后从井沿消失，换房和安全存档保留空钩状态。

开场可先查看相框布角，再主动揭开黑布；只看或离开不关门。揭开后画面保留父亲遗像，可回查背面名字和守灯纸条，重入与存档继续保持，不重复触发门闩。

手记中的新观察会记下地点，展开后可回想去现场的已知路线；路线图选中房间，也能回查在那里记下的发现。门锁和已走通路仍然有效，旧记录不会自动猜测地点。

学校与医院记忆由玩家主动进入，可从暂停或拼合界面暂回旧宅、保留已读线索。之后能重访，也可在宅内手记提交判断；正确提交才算完成并更新走廊变化，暂离不会自动解谜。外部追逐仍存在时，回宅会恢复追逐和入场预警。

学校黑板、红笔成绩单、诊室窗口、空病床和事故护栏已有专用像素外形，可从场景中辨认调查对象与对应痕迹；完整记录继续在阅读界面和手记中回查。

拼合判断时，两份已选原文与来源会直接放在解释选项上方，可对照或换掉其中一份。判断失败会提示该核对的书写者、时间或痕迹，选择保留，不逐张判分；正确物证与解释提交后才完成。

走廊钉死的窗户已有可见外形，窗扣、横木和钉痕对应具体观察。调查原文会留在手记中，可回查走廊来源，重复读取不增加物证计数。

厨房饭碗和暗室火柴能在场景中看见，调查后可拿走或留在原处。取走后留下碗印和浅方印，换房与存档保持已取外形。

旧卧室的日记已接入实际调查，绘在桌面上方，原文可从物证卡回查；同屋衣柜也接通了躲藏交互。

棺上三圈红线会随学校、守灯和医院完成分别松开，可观察并记录纸片与结的状态。锁仍需红钥匙，满足条件后由玩家确认开棺，再进入最后记忆。

终章的山路与回宅方向已有路标石阶、亮着灯的旧门口和明确调查名称；靠近不会自动决定去留，仍需主动确认。

主动提示会优先照顾当前房间和已完成的步骤，再回到全局目标；材料已齐时提示从手记判断，守灯中途可按剩余步骤继续。

暗室笔记、红字和地下室抓痕、藏起的纸条读过后也会留在手记，可按地点回查；这些环境观察不增加核心物证计数。

手记、路线和解谜层可用 Tab/Shift+Tab 在当前层内操作，Esc 合上；换页从标题开始，关闭后返回原入口。保险箱继续支持数字键输入。

被抓后已读记录、路线与已提交判断保留，物品和现场仍按入房检查点恢复。安全暂停退出会先保存最新内容；追逐或躲藏时，返回标题会使用上次安全记录。

地下室、阁楼和暗室等房门的入房落点已对齐对应入口，便于辨认方向；房间连接、钥匙与暗门条件保持。

双击 `index.html` 即可运行。标题的 Enter/空格进入或继续游戏，Shift 奔跑，E 调查，J 看手记，M 回看走过的路（手机从手记进入）；物件显示已调查、内容变化或待完成状态。移动端增加按住奔跑按钮。声控躲藏改为暂停菜单自愿开启，不开启麦克风仍可通关。安全房间自动存档；“重新开始”先确认，默认保留进度，明确清除后才重开。

封存时的剧情与规则见 [2D 调查篇说明](docs/2D_STORY.md)，实现和验证边界见 [2D 改造记录](docs/2D_REWORK.md)。后续研发转入独立 3D 仓库。

## ✨ 游戏特色

- 🕯️ **中式民俗恐怖**：纸人、棺材、冥币、牌位……还原最真实的童年阴影。
- 🔦 **沉浸式光影探索**：在伸手不见五指的黑暗中，你唯一能依靠的只有手中那束微弱的手电筒光。
- 🎙️ **可选声控躲藏**：在暂停菜单开启后，持续声音会暴露藏身位置；普通躲藏不需要麦克风。
- 🧩 **碎片化叙事**：通过日记、遗书和奇怪的道具，拼凑出一个关于“爱与控制”的悲剧真相。

## 🎮 游戏操作

### 💻 电脑端
- **移动**: `W`, `A`, `S`, `D` 或 `方向键`
- **交互/调查**: `空格键 (Space)` 或 `E` 键
- **鼠标**: 点击屏幕上的按钮也可进行交互

### 📱 移动端
- **移动**: 左下角虚拟摇杆
- **交互**: 右下角“查”字按钮
- **横屏体验**: 建议在手机浏览器中开启“自动旋转”并横屏游玩，获得最佳沉浸感。

## 🕹️ 游戏目标
你需要扮演一名迷路的人，在雨夜中误入一间诡异的灵堂。
通过探索环境、收集物品（火柴、贡品），解开灵堂的秘密，并最终揭开故事的真相。

## 🚀 快速开始 (推荐)
直接双击运行目录下的 `StartGame.bat` 即可自动启动服务器并打开游戏。

## 🧪 3D 原型
旧原型已废弃，不作为新版继续打磨。`prototype3d.html` 与原始素材只在本地保留，3D 新版请访问独立仓库。

3D 美术不建议直接在代码里硬搓。后续生成老宅场景、贴图和道具参考时，优先使用 `docs/3D_ART_PROMPTS.md` 里的完整提示词包。

`美术/` 是本地保留的旧 3D 源素材库，不随本仓库的 2D 版本上传。新版的真实模型、PBR 材质及其许可在独立 3D 仓库中维护。

## 🛠️ 本地运行 (手动)
如果你想手动运行：
1. 右键点击 `server.ps1`，选择“使用 PowerShell 运行”。
2. 浏览器访问 `http://localhost:8000`。

## 🧰 维护说明
`index.html` 是 2D 可直接打开的单文件入口，源码以 `src` 目录为准。历史构建方法是运行 `node tools\build_standalone_entry.mjs`，再运行 `node tools\verify_standalone_entry.mjs`。2D 已停止研发，3D 构建与检查在独立仓库中执行。

2D 新玩法用 `node tools\verify_2d_gameplay.mjs` 验证物证门槛、仪式重试、记忆完成、结局确认、安全存档与奔跑时间；原有 `verify_story_state.mjs`、`verify_maps.mjs`、`verify_start_route.mjs` 继续保留。脚本检查不能替代浏览器试玩。

追逐与环境节奏用 `node tools\verify_horror_pacing.mjs` 检查可达生成、入场预警、阅读期间冻结、记忆回返、活动时间计量与环境声来源。修改相关源码后，仍需先重建单文件入口。

2D 图片清单在 `src/data/ArtAssets.js`，原图在 `assets/2d/`。修改资源后同样需要重建入口；入口校验包含图片字节一致和启动等待/失败回退。当前入口约 3.63 MB，真实手机首屏性能尚未验收。

## 📦 部署与分享
本项目为纯静态网页，推荐使用以下方式分享给朋友：

### 1. Netlify Drop (最快，无需注册)
- 访问 [Netlify Drop](https://app.netlify.com/drop)。
- 将项目根目录中的静态文件拖入网页，核心文件包括 `index.html`、`src/` 和 `phaser.min.js`。
- **注意**：如果不登录账号，生成的链接有效期仅为 **24小时**。
- **永久保存**：在该页面注册/登录 Netlify 账号并“认领”该站点，链接即可永久有效。

### 2. GitHub Pages (永久，适合开发者)
- 将项目上传至 GitHub 仓库。
- 在仓库 Settings -> Pages 中开启服务。
- 链接永久有效。

### 3. Vercel (永久，速度快)
- 注册 Vercel 账号并关联 GitHub 仓库即可自动部署。
